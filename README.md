# Travel Fare Calculator

## This program uses the distance, fare rate, and the number of passengers to calculate the total travel fare rate.

## Version 1 – Original code without input validation

## Input Needed
- name
- distance
- passengers

## How to Run
1. Open the program file in VS Code, Replit, or Google Colab.
2. Run the program.
3. Enter the values for name, distance, and passengers.
4. Check the travel fare rate displayed on the screen.

## Sample Output
Passenger: name
Total Fare: total fare
